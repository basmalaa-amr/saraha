# Saraha-app   
* tech :
    - express
    - mongoose / mongoDB
    - redis for caching
    - JWT
    - hash-password
    - login with google
    - rate-limiter

* phase one:  

- auth flow: [register, verify-account, login, forget-password, send-otp].   

- message flow: [send-anonymous-message, send-public message, view-all-messages]. 

* phase two: 

- auth flow: [ login-with-google, refresh-tokens, save-otps-cache-layer].   
- message flow: [request-to-know-who-send-this-message, accept, decline, start-conversation].
